# renovate-config

Centralized Renovate configuration for `crxig-rxberts` projects.

## Usage

Use the latest tag as a reference from the [latest release](https://github.com/crxig-rxberts/renovate-config/releases/latest).

```json
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": ["github>crxig-rxberts/renovate-config#0.3.1"]
}
```

## Configuration

The Renovate configuration is available at [default.json](./default.json).
